# soloquesttribe here 👋

I build mobile apps that hopefully don't crash when the train goes underground. Flutter and React Native are my main tools, and I have a soft spot for animations that feel like butter on a warm pancake. Lately I've been obsessed with offline-first architectures because nothing beats an app that works when the wifi doesn't.
